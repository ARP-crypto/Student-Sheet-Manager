# Student-Sheet-Manager
A professional full-stack student data management system with spreadsheet-style records, CRUD operations, search, analytics, and Excel/CSV import &amp; export.
Project Description:
Student Sheet Manager is a full-stack web application designed to help educational institutions, faculty, and administrators efficiently store, manage, search, and analyze student information. The system provides a spreadsheet-style interface for maintaining student records such as name, age, student ID, course, year, section, email, phone number, attendance, and status.

The application includes CRUD operations, search and filtering, dashboard statistics, attendance and course analytics, Excel/CSV import and export, data validation, and persistent storage. It is designed with a responsive and professional interface, making it suitable for academic administration, college projects, internships, and portfolio demonstrations.
